# 하수관 AI 정비대

이 프로젝트는 도트풍의 하수관 관리 시뮬레이션 게임입니다.

## 실행 방법

브라우저에서 `index.html` 파일을 직접 열면 됩니다.

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000` 을 열면 됩니다.

## 게임 구성

- 시작 화면: 둥근 하수도 파이프와 물 흐름 배경
- 게임 화면: 4개의 CCTV 모니터, AI 위험도 예측, 경사하강법 학습
- 7일 달력: 매일 결과를 O/X로 기록
- 결산 화면: 5회 이상 성공 시 승진, 3~4회는 재도전, 3회 미만은 해고

## 핵심 게임 메커니즘

- 각 관로는 압력, 소음, 침전물, 부식 데이터를 가집니다.
- AI는 간단한 선형 모델과 경사하강법으로 위험도를 학습합니다.
- 사용자는 모니터를 누르며 이상 관로를 선택합니다.
- 예측이 맞으면 성공, 틀리면 오차를 반영해 모델 가중치를 수정합니다.

## 파일 구조

- `index.html` : 게임 구조
- `style.css` : 도트풍 UI와 화면 디자인
- `script.js` : 게임 로직과 경사하강법 학습
